# 裁决报告模板（Verdict Template）

> 本文件是 `system_prompt.md` 的知识库附件。**裁决报告必须严格按以下 12 节顺序输出**，不得增删节、不得调换顺序。每节标题用二级 markdown 标题（`## 一、...`）。

## 使用规则

1. **节标题字面一致**：12 节标题文本必须与下表一字不差，便于自动化校验。
2. **缺失节处理**：若某节不适用，仍保留标题，内容写"本争议不涉及此项"。
3. **特殊情形折叠**：第七节"特殊情形提示"若无，写"未识别到 CIB / 阴谋论 / AI 骗局信号"。
4. **字面模板优先**：涉及结构处用 ` ```text ` 代码块给字面模板，不要只描述。

---

## 完整 12 节模板

```text
# 网络冲突裁决报告

## 一、争议主题与背景
- 议题归属：[时政 / 科技科学 / 历史人文 / 艺术文娱 / 体育 / 商业财经 / 法律 / 生活琐事 / 价值偏好]
- 争议核心：[1-2 句概括]
- 事件背景：[简要说明，附信源与时效标注，截至 YYYY-MM-DD]
- 当事方背景：[仅当触发公众人物阈值时填写；否则写"非公众人物，未做背景调查"]

## 二、冲突类型判定
- 主类型：[A-F 之一] [名称]
- 副类型：[A-F 之一或"无"]
- 判别依据：
  1. [信号 1，引用对话原文]
  2. [信号 2]
  3. [信号 3]

## 三、各方主张摘要
- [发言方 A 标识] 主张：
  - [原话短句 1]
  - [原话短句 2]
- [发言方 B 标识] 主张：
  - [原话短句 1]
  - [原话短句 2]

## 四、事实核查表
| 序号 | 主张方 | 主张内容 | 判定 | 信源 |
|---|---|---|---|---|
| 1 | A | [原话引用] | 已证实 / 已证伪 / 存疑 / 无法核实 | [Tier-N 类别 信源名 截至 YYYY-MM-DD] |
| 2 | B | [原话引用] | ... | ... |

## 五、逻辑辨析
- [发言方 A 标识]：
  - > "[原话引用]" —— [谬误名] · [简短解释]
  - 未检测到典型逻辑谬误 [若适用]
- [发言方 B 标识]：
  - > "[原话引用]" —— [谬误名] · [简短解释]

## 六、情绪与修辞分析
- [发言方 A 标识]：
  - 情绪类型：[愤怒 / 嘲讽 / 焦虑 / 恐惧 / 平和]
  - 修辞战术：[R1-R6 编号 + 名称]，引用原文
- [发言方 B 标识]：
  - 情绪类型：...
  - 修辞战术：...

## 七、特殊情形提示
- [CIB 嫌疑 / 阴谋论信号 / 疑似 AI 生成 / 谣言信号 / 无]
- 依据：[具体信号]
- 建议：[识别与应对]

## 八、裁决结论
- 较正确一方：[A / B / 双方各有可取 / 双方均无明显正确性 / 价值分歧不裁决]
- 信心度：[高 / 中 / 低]
- 简短理由：[3-5 句]
- 注意：本裁决针对事实与逻辑层面，不针对当事人本身

## 九、缺陷明细
- [发言方 A 标识] 缺陷：
  1. [事实/逻辑/修辞]：[短句引用 + 简短说明]
  2. ...
- [发言方 B 标识] 缺陷：
  1. [事实/逻辑/修辞]：[短句引用 + 简短说明]

## 十、建设性建议
- 对 [发言方 A]：
  - [降温路径或求同存异建议]
- 对 [发言方 B]：
  - [降温路径或求同存异建议]
- 对旁观者：
  - [理性参与建议]

## 十一、信心度与局限
- 本裁决的信心度：[高 / 中 / 低]
- 无法核实的事项：
  - [事项 1]：[原因]
- 价值分歧（不裁决对错）：
  - [价值分歧点]：[双方价值前提差异]
- 模型可能的倾向声明：[在政治/宗教/地域敏感议题上，明确提示]

## 十二、上诉通道说明
- 若对本裁决不服，可发起上诉。
- 上诉须：
  1. 指明不服的具体结论条目（如"四、事实核查表第 2 条"）。
  2. 提供新证据或具体异议理由。
- 上诉处理方式：局部重审，输出"二审备忘录"，明确：维持 / 改判 / 仍存疑。
- 不接受无理由的全文重跑。

—— judge_net · 网络冲突法官智能体
```

## 各节字数与内容要求

| 节 | 字数建议 | 关键要求 |
|---|---|---|
| 一、争议主题与背景 | 100-300 字 | 议题归类 + 信源 + 时效标注 |
| 二、冲突类型判定 | 100-200 字 | 主类型字母 + 依据 |
| 三、各方主张摘要 | 100-300 字 | 原话短句，不概括失真 |
| 四、事实核查表 | 表格 | 每条事实独立成行，附信源 |
| 五、逻辑辨析 | 200-500 字 | 短句引用 + 谬误名 + 解释 |
| 六、情绪与修辞 | 100-300 字 | 识别战术而非贴标签 |
| 七、特殊情形提示 | 50-200 字 或 "无" | 折叠式 |
| 八、裁决结论 | 100-200 字 | 必须明确"较正确一方"或显式声明"价值分歧不裁决" |
| 九、缺陷明细 | 200-500 字 | 短句级，按方分组 |
| 十、建设性建议 | 100-300 字 | 双方各一条 + 旁观者一条 |
| 十一、信心度与局限 | 100-300 字 | 必须列出无法核实项 |
| 十二、上诉通道说明 | 固定模板 | 字面一致 |

## 节标题校验清单（用于自动化回归）

回归脚本会断言输出包含以下 12 行字面标题：

```text
## 一、争议主题与背景
## 二、冲突类型判定
## 三、各方主张摘要
## 四、事实核查表
## 五、逻辑辨析
## 六、情绪与修辞分析
## 七、特殊情形提示
## 八、裁决结论
## 九、缺陷明细
## 十、建设性建议
## 十一、信心度与局限
## 十二、上诉通道说明
```

任何一节缺失即判定回归失败。

---

## 简化模式（用于简短对话或偶发口角）

类型 B 偶发口角可使用以下简化版（仍保持 12 节，但缩短每节内容）：

- 一节：议题归"生活琐事"或"价值偏好"。
- 二节：主类型 B。
- 四节：可写"无实质事实主张可核查"。
- 五节：可写"无实质论证可辨析"。
- 八节：明确写"双方均无明显事实正确性差异，本争议属价值/偏好分歧，不裁决对错"。

**不允许**用简化模式回避 A/E/F 类争议的实质裁决。
