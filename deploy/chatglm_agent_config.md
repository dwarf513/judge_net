# 智谱清言智能体配置指引

> 本文件指导你在智谱清言（chatglm.cn）平台手动创建 judge_net 智能体并生成分享链接。
> opencode 不代登平台，以下步骤需你本人操作。

## 一、前置准备

### 1.1 账号

- 访问 https://chatglm.cn
- 用手机号或微信登录（若无账号需注册）。

### 1.2 文件准备

确认本仓库以下文件就绪（已在本地生成）：

| 用途 | 文件路径 |
|---|---|
| 主系统提示词 | `system_prompt.md` |
| 知识库 1 | `knowledge/fallacy_taxonomy.md` |
| 知识库 2 | `knowledge/conflict_typology.md` |
| 知识库 3 | `knowledge/source_credibility.md` |
| 知识库 4 | `knowledge/verdict_template.md` |
| 知识库 5 | `knowledge/appeal_protocol.md` |
| 知识库 6 | `knowledge/response_script_guardrails.md` |
| 知识库 7 | `knowledge/safety_refuselist.md` |

用文本编辑器打开每个文件，**全选复制**内容备用。

## 二、创建智能体

### 2.1 进入创建入口

1. 登录后，在左侧导航栏或顶部菜单找到"创建智能体"（或"我的智能体"→"新建"）。
2. 选择"自定义智能体"类型。

### 2.2 基础信息

| 字段 | 填写内容 |
|---|---|
| 名称 | judge_net · 网络冲突法官 |
| 简介 | 网络争吵的公正裁决者：厘清事实、辨别谬误、看见降温路径，促进网络和谐。 |
| 头像 | 可用默认，或上传一张天平/法槌风格图片（避免敏感符号） |

### 2.3 人设与能力（核心）

在"人设与能力"或"系统提示词"配置框中：

1. **粘贴 `system_prompt.md` 全文**。
2. 确认粘贴完整，无截断（约 550 行）。

> 若平台对系统提示词长度有限制（如单框上限 < 30k 字符），可：
> - 将 `knowledge/*.md` 内容作为知识库上传（见下节），主提示词保持完整。
> - 主提示词中已用文件名引用各知识库，平台检索时会自动调用。

### 2.4 知识库配置

在"知识库"或"附件"配置项中：

1. 逐个**新建知识条目**，每个条目对应一个 `knowledge/*.md` 文件。
2. 条目标题用文件名（如 `fallacy_taxonomy`），内容粘贴对应文件全文。
3. 共 7 个条目，全部上传。

> **注意**：知识库条目名建议与 `system_prompt.md` 第 14 节引用清单一致，便于平台检索匹配。

### 2.5 工具与能力勾选

在"工具"或"能力"配置项中，**勾选以下**：

| 工具 | 是否启用 | 用途 |
|---|---|---|
| 联网搜索 | **必须启用** | 即时研究、事实核查、信源检索 |
| 文件/图片上传 | **必须启用** | 用户上传对话截图 |
| 图像理解（GLM-4V） | **必须启用** | 截图 OCR 与角色分割 |
| 代码执行 | 不需要 | 本智能体不写代码 |
| 函数调用 | 不需要 | 低代码路线无自定义函数 |
| 多智能体协作 | 不需要 | 单智能体即够 |

### 2.6 模型选择

若平台允许选择底层模型：

- **对话模型**：选 GLM-5.2 或最新可用版本（reasoning 能力强，适合三层分析）。
- **视觉模型**：选 GLM-4V 或最新可用版本（截图识别）。

### 2.7 开场白

在"开场白"或"欢迎语"配置项中，粘贴 `system_prompt.md` 第 15 节"默认开场白"的内容：

```text
你好，我是 judge_net——网络冲突法官智能体。

我可以帮你看清一场网络争吵：
- 复制粘贴对话原文，或上传截图。
- 我会梳理事实、辨别逻辑、识别修辞战术。
- 输出一份 12 节裁决报告，明确指出较正确一方，或显式声明"价值分歧不裁决对错"。

我能做的：
- 时政、科技、历史、法律等可核实议题：基于权威信源做事实核查与逻辑辨析。
- 价值偏好、审美、生活琐事：只澄清双方前提差异，不判对错。
- 识别水军、阴谋论、AI 骗局等特殊情形。

我不能做的：
- 不对未成年人、未决司法案件、暴力威胁做裁决（会转介专业资源）。
- 不人肉、不替你骂人、不编造证据。
- 不评价你或对方"是什么样的人"，只评价论点与论证。

请提交争议对话。若是截图，建议先截完整对话，多张图按时间顺序上传。
```

### 2.8 快捷指令（可选）

若平台支持快捷指令，可添加：

| 指令 | 触发词 | 行为 |
|---|---|---|
| 裁决 | `/裁决` | 提示用户粘贴对话或上传截图 |
| 上诉 | `/上诉` | 提示用户指明不服条目 + 提供新证据 |
| 应答话术 | `/话术` | 触发 opt-in 流程 |
| 帮助 | `/帮助` | 显示能力清单与禁止项 |

## 三、发布与分享

### 3.1 保存并预览

1. 完成上述配置后，点击"保存"或"发布"。
2. 在预览区用金标准案例测试一轮：
   - 粘贴 `golden_cases/case_01_weibo_knowledge_debate.md` 中"对话原文"部分。
   - 确认输出包含 12 节标题 + 关键判定（参考 `expected_outputs/case_01_expected.md`）。

### 3.2 生成分享链接

1. 在智能体管理页找到"分享"或"发布链接"。
2. 生成分享链接（形如 `https://chatglm.cn/share/xxxxx`）。
3. 复制链接。

### 3.3 回填链接到 README

1. 打开本仓库 `README.md`。
2. 找到"智能体分享链接"占位符。
3. 替换为你的实际链接。
4. 用 `git add README.md && git commit -m "回填智能体分享链接"` 保存（参见 `docs/git_tutorial.md`）。

## 五、常见问题

### Q1：平台提示系统提示词过长

- 确认 7 个知识库文件已作为独立条目上传到知识库。
- 主提示词中第 14 节已用文件名引用，平台会按需检索，无需全部内联。
- 若仍过长，可精简 `system_prompt.md` 第 13 节"互动与温度"（非核心）。

### Q2：知识库检索不到内容

- 确认知识条目标题与 `system_prompt.md` 第 14 节引用清单一致。
- 平台可能需要几分钟索引，等待后重试。
- 若仍不检索，可在主提示词中把关键模板（如 12 节标题）内联，不依赖知识库。

### Q3：截图识别效果差

- 确认已启用 GLM-4V 或图像理解能力。
- 建议用户上传清晰截图，避免模糊、截断、多图混乱。
- 复杂截图可让用户先用文本补充发言方归属。

### Q4：联网搜索未触发

- 确认"联网搜索"工具已勾选。
- 在主提示词中已指令"对可核实议题执行即时研究三件套"，平台应自动调用。
- 若仍不调用，可在用户消息中显式提示"请联网检索 X"。

### Q5：分享链接打不开

- 确认智能体已"发布"而非仅"保存草稿"。
- 检查分享权限设置（公开/私密）。
- 平台偶有维护，过几分钟重试。

## 六、后续迭代

平台上线后，迭代流程：

1. 本地修改 `system_prompt.md` 或 `knowledge/*.md`。
2. 跑 `python3 scripts/regression_test.py` 验证（参考 `docs/git_tutorial.md` 第 6.2 节）。
3. 通过后，复制新内容到平台对应配置框。
4. 重新生成分享链接（若平台支持保留旧链接则无需）。
5. `git add . && git commit -m "迭代说明"` 保存版本。

> 平台配置与本地仓库可能短暂不一致——以本地仓库为权威源，平台是部署镜像。
