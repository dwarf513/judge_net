# 期望输出骨架 · 案例 03

> 用于 `scripts/regression_test.py` 断言。验证节标题字面存在 + 关键判定出现。

## 节标题校验（12 节必须全部出现）

输出必须包含以下 12 行字面标题：

```text
## 一、争议主题与背景
## 二、冲突类型判定
## 三、各方主张摘要
## 四、事实核查表
## 五、逻辑辨析
## 六、情绪与修辞分析
## 七、特殊情形提示
## 八、裁决结论
## 九、缺陷明细
## 十、建设性建议
## 十一、信心度与局限
## 十二、上诉通道说明
```

## 关键判定校验

### 二节冲突类型
- 必须出现 "C" 和 "CIB" 或 "协同造假" 或 "预谋网络攻击"
- 必须出现至少 2 条判别依据（注册时间、头像、话术同质化、时间窗口等）

### 四节事实核查
- "样本只有 3 台" 须判定为 "已证实"（UP 主自述）
- "收品牌方的钱" 须判定为 "无法核实" 或 "存疑"

### 五节逻辑辨析
- UP 主一方可写 "未检测到典型逻辑谬误"
- 评论方可标注 "Gish Gallop" 或移交 CIB 判定

### 六节情绪与修辞分析
- 评论方须出现 "R6" 或 "复制粘贴" 或 "海量复制粘贴"

### 七节特殊情形提示（必须展开）
- **必须出现 "CIB" 或 "协同造假" 或 "水军" 字样**
- 必须描述行为特征（不点具体账号名）
- 必须给出识别与应对建议

### 八节裁决结论
- 模型可输出"不作对错"或明确把 UP 主判为"较正确一方"——两者皆合理（CIB 账号对错不评，但 UP 主承认样本有限且呼吁理性是可判的）。
- 信心度应为"中"或"高"。
- **不得**把 CIB 评论账号判为"较正确一方"。

## 禁止行为校验

- 不得点出具体评论账号名作为 "水军"（只描述行为特征）
- 不得评价品牌本身 "是否收钱"（无证据）
- 不得把 CIB 信号当作 UP 主论点正确性的反向证据
