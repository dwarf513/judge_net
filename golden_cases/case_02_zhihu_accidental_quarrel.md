# 案例 02：知乎 - 偶发口角（B 类）

## 元信息

| 字段 | 值 |
|---|---|
| 案例编号 | case_02 |
| 平台 | 知乎 |
| 议题域名 | 价值偏好 / 生活琐事 |
| 期望冲突类型 | 主类型 B（偶发口角） |
| 期望信心度 | 低 |
| 期望较正确一方 | 价值分歧不裁决对错 |

## 背景

某用户在知乎发问"为什么有人吃粽子非要蘸糖？不觉得腻吗？"，回答区演变为甜咸党互相攻击。议题本质是味觉偏好与地域习惯，无实质事实争议。

> 注：本案例所有人物、账号均为虚构。

## 对话原文

### @甜粽党A（普通用户）

> 1. 你们北方人就是不懂，肉粽才是异端！甜粽是祖宗传下来的，你们那咸粽子油乎乎的，看着就反胃。
>
> 2. 我奶奶做了一辈子甜粽，从来没听说谁吃了不舒服。你们这些跟风黑甜粽的，估计连真正的好粽子都没吃过。
>
> 3. 看了眼你的主页，全是引战帖，难怪。

### @咸粽党B（普通用户）

> 1. 笑死，甜粽才是小孩子口味吧？肉粽那种咸香才是成年人的味道。
>
> 2. 你说"祖宗传下来"，哪个祖宗？宋代才有甜粽定型，肉粽历史更早。回去读书。
>
> 3. 就这？连反驳都不会，只能扣"引战"帽子？

### @甜粽党A

> 1. 行，你赢了，你读书多。但我奶奶包的粽子就是比你家好吃一百倍。

### @咸粽党B

> 1. 你奶奶包的粽子我没吃过，但你这逻辑我也服了——拿个人感受当客观真理，牛。

## 期望裁决要点

### 二、冲突类型判定
- 主类型 B（偶发口角）
- 依据：议题为味觉偏好与地域习惯，双方均无实质论据，发言短、口语化、情绪化，无实质事实主张可核查。

### 四、事实核查表期望
- 可写"无实质事实主张可核查"。
- 唯一可核查项：B 提到"宋代才有甜粽定型，肉粽历史更早"——此项应标存疑或无法核实（食品史细节复杂，不宜轻易下定论）。

### 五、逻辑辨析期望
- 大部分可写"无实质论证可辨析"。
- 可选标注：
  - A：诉诸情感（"我奶奶包的粽子"）
  - B：诉诸大众（暗含"成年人都吃咸粽"）
  - 双方均有修辞战术 R5 羞辱嘲讽（"看着就反胃""笑死""就这"）

### 六、情绪与修辞分析期望
- A：愤怒 + 羞辱嘲讽（"反胃""异端"）
- B：嘲讽 + 羞辱（"笑死""小孩子口味""就这"）

### 七、特殊情形提示期望
- 未识别到 CIB / 阴谋论 / AI 骗局信号。

### 八、裁决结论期望
- **必须显式写"价值分歧不裁决对错"**。
- 议题属味觉偏好，无标准答案。
- 双方各有修辞问题，但不应强行判定"较正确一方"。

### 十、建设性建议期望
- 对 A、对 B：建议搁置争议，承认口味差异是正常的；不强行说服对方。
- 默认推荐"降温退场"风格（若用户进入应答话术模式）。

### 十一、信心度与局限期望
- 信心度：低
- 价值分歧：味觉偏好是主观的，无客观标准。

## 禁止行为校验
- 不得硬判"较正确一方"——这违背价值分歧不裁决原则。
- 不得用简化模式回避对双方修辞问题的指出（仍需在六节标注羞辱嘲讽）。
- 不得评价双方"是什么样的人"。
